# 1.53d-beta-17

- Remove the custom search and number-field renderer. Use the same native Minecraft EditBox factory for the main settings screen and item assignment controls, retaining the normal border, text padding, cursor and focus behavior.
- Move assignment panel geometry, toolbar positions, footer and standard control/grid dimensions into GuardUiLayout. Keep the item tiles and permanently visible Assigned panel; render that panel using the shared sidebar style.
- Open Item Block Counts through the combined whitelist/blacklist editor. Left-click allows, right-click blocks, and either click clears an explicitly assigned item. The same screen retains group rules, exceptions, conflict prompts and editable block counts.
- Put the new-item limit beside Assigned, separated from Search and Rule. Allowed individual items receive that limit; group rules do not create per-item count overrides. Existing count-only overrides remain visible without implicitly whitelisting them. Blank individual limits restore default/compatibility behavior.
- Preserve defaults, parent pausing, category filters, bulk operations and independent draggable scrollbars. No new Java source files or network/config schema changes.

Validation: dependency-fixture compilation of actual controls, assignment screen, rule matching and main config entry handlers. Checked actual item-grid right-click through the block-count entry, paired list saving, opposite-click removal, per-item count saving, filters, bulk conflicts, scroll dragging and narrow layouts. All 80 Java files parsed. Full Gradle compilation and Minecraft visual testing were not run here.

# 1.53b-beta-7

Adds optional client particle collision profiling for Flying Sparks and Spark Debris. Particle appearance, movement, intensity and collision behavior are unchanged.

Enable Particle Collision Profiling under `/mgc` → Debug → Diagnostics. It is off by default and stays off when ordinary Diagnostic Logging is enabled. Reports aggregate 100 advancing game ticks and separate slow collision checks, first fast checks and second fast checks for each effect.

Reports include query counts, blocked queries, total query time, average time per query, average and peak query time per tick, second-check percentage and peak active head count. Timing includes measurement overhead and query setup; it excludes bounce response and rendering. These are collision measurements, not total mod cost or FPS measurements.

See `particle-collision-profiling.md` for testing instructions. This remains a beta release while the reported Punchy animation issue is unresolved.

Validation: Java syntax parsing, profiler aggregation checks with isolated API stubs, and comparison of particle movement code against beta-6. No game build or in-game performance test was run.

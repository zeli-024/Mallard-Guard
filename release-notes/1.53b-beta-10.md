# 1.53b-beta-10

All Aurukel test controls now sit under one Aurukel Sparks divider in `/mgc` → Client → World Particles. Its enable switch selects the test effect; the divider exposes every setting together, even while the effect is disabled.

Four separate start/end size controls are replaced by Overall Size and Head Size. Overall Size scales the head and all trail dots together from a baseline quad half-size of 0.05 → 0.03 blocks. Head Size multiplies only the head size afterward. Both default to 100%. Overall Size ranges from 0–2000%; Head Size from 0–1000%. Collision Size remains separate from visible size.

Launch Speed now ranges from 0–3000%. Trail Dots ranges from 0–256 per head per tick. Fixed Dot Distance ranges from 0.001–10.000 blocks and displays three decimal places. Arrow keys or the mouse wheel change it by 0.001 blocks; Shift changes it by 0.010. Fixed spacing carries distance across ticks and emits at most 256 dots per head per tick. All Aurukel numeric controls use individual steps rather than ten-percent rounding.

The upward-bias experiment is replaced by the shared heavier-side spread calculation used by Flying Sparks and Spark Debris. Each burst chooses a random heavier side and accepts directions across the surrounding sphere. Spread Bias controls its strength, defaulting to 40% as for Flying Sparks. It does not point the burst upward or restrict it to a cone. The original effects already share their burst's heavier side; trail dots follow their head's path. Aurukel head physics after launch and captured white → orange → grey trail colors remain unchanged.

The replaced size, spacing and spread controls use new config keys and defaults. Older presets receive valid defaults for these controls; other settings remain intact. Existing individual start/end size curves are replaced by the shared 60% end-size ratio. Particle page reset now includes all Aurukel settings.

Validation: syntax parsing of 69 Java sources, isolated configurable-particle checks, preset migration and bounds checks, 10,000 matching normalized launch directions against Flying Sparks with matching seeds/settings, extended-speed endpoint, divider/binding/display checks, and comparison confirming existing particle physics/rendering/profiler code is unchanged. No Minecraft build or in-game test was run. Remains a beta while the reported Punchy animation issue is unresolved.

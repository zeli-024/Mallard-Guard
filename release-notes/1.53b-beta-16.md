# 1.53b-beta-16

- Replaced Shooting Sparks' stretched rectangular trail with stationary, upright square pixels. There is no stretched-line mode.
- Added Shooting Squares per Tick to the existing Shooting Sparks settings group and search. Default 24; range 0–256; zero disables the trail.
- The requested square count is shared across each tick's traveled path, including rebounds. Longer travel produces wider gaps. Bounces do not multiply the count or create bridges through surfaces.
- Square positions are calculated once during ticking and retained in bounded primitive arrays. No separate trail particle objects are created.
- Head movement, gravity, drag, bounce, and selected settings remain unchanged.
- Disabled, transparent, zero-size, or zero-count trails allocate no sample history and add no extra head lifetime.
- Expiry and conservative visibility checks reject trail drawing early. Offscreen physics continues.
- Camera-aligned square offsets are reused across the trail. Spark Debris also reuses its tail corner offsets.
- Earlier presets retain existing settings and receive the new square-count default without shifting other settings.

Validation: 72 Java sources parsed; isolated checks passed for count, spacing, upright geometry, birth timing, fixed stored positions, bounce paths, impact-time interpolation, inactive cleanup, offscreen movement, bounded storage, expiry, and preset migration. An in-game build, visual test, and performance measurement remain necessary.

Use `bash ./apply-source-cleanup.sh` before building when overlaying an older source package. Remains beta while rapid Punchy animations can fail to render.

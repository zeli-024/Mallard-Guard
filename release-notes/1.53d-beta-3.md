# 1.53d-beta-3

- Reordered Shooting Sparks controls within its existing divider: amount, launch, physics, bounce, appearance, lifetime, fading, and shrinking.
- Replaced Motion Variance with Gravity Variance, Velocity Loss Variance, and Fade Variance. Every variance slider now uses the full 0–100% range directly, from exact values to zero–twice the configured value.
- Shared Lifetime Variance controls head and trail lifetimes. Shared Fade Variance controls their fade durations. Each random multiplier is selected once at spawn.
- Retained selected amount, launch, gravity, loss, bounce, appearance, lifetime, fade, and shrink defaults. Separate gravity/loss variance defaults to 20%, lifetime to 10%, and fade to 25%. Launch speed variation now follows the same symmetric rule, retaining its baseline and mean speed.
- Updated labels, tooltips, search entries, and older preset/config migration. Retired Motion Variance no longer appears in the UI or generated config.
- Preserved upright stationary squares, complete tick groups, bounced paths, simultaneous effects, and shared rendering budgets.

Validation: Java syntax and isolated movement, dot-group rendering, variance ranges, configuration/preset migration, and spawn/budget checks. In-game testing remains necessary.

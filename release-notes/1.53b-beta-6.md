# Mallard Guard 1.53b-beta-6

Clarifies the implementation of the two existing particle effects. The core files are now GuardParryParticle, GuardParryParticleSpawner, GuardParryParticleMath, and GuardParryParticleRenderer. An explicit FLYING_SPARK / SPARK_DEBRIS type replaces the misleading streak boolean. Registry fields, intensity fields, helper methods, and spawner variables now identify the effect they handle.

Removes an unnecessary clear forwarding method, shares the spherical direction-acceptance formula, and centralizes the existing burst and active-head limits. Shared collision and rendering code and the separate pure math helper remain to avoid duplication and keep responsibilities clear.

Flying Sparks and Spark Debris preserve beta-5 defaults, formulas, random variation, collisions, and rendering behavior. Existing config keys and registry/resource identifiers remain compatible. Shooting Tracers and the Terramity comparison test are absent.

Java syntax, source equivalence, and particle math checks were performed. A local game build is still required. Beta status remains because rapid Punchy animation use can intermittently fail to render.

# 1.53b-beta-13

- Added Shooting Sparks: one physical head with stretched-dot trail segments stored inside the head.
- Trail length follows actual movement. Segments split at impacts, and the head follows the same path during rendering between ticks.
- Shared spread and reflection calculations provide a surrounding burst with a randomly favored side, varied launch speeds, weakening rebounds, and surface friction.
- Added one Shooting Sparks settings group for intensity, size, launch, gravity, drag, bounce, variation, lifetime, and fade.
- Kept the small white head and 65% trail opacity as the visual starting point. No separate trail particle objects are emitted.
- Added Shooting Sparks collision query timings to the optional profiler.
- Existing presets retain their slots and receive defaults for the appended settings.

Shooting Sparks is enabled for this test and takes priority over Aurukel Sparks. Disable Shooting Sparks to return to the Aurukel test; disable both to see Flying Sparks and Spark Debris.

Validation: all 72 Java source files parsed; isolated Java checks passed for motion, rebound paths, interpolation, collision query limits, settling, bounded trail storage, expiry, and preset migration. A Minecraft build and visual/performance test remain necessary.

Remains beta while the rapid Punchy animation issue is unresolved.

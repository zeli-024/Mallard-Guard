# 1.53b-beta-12

Uses all 27 Aurukel settings from the supplied client config as defaults. The effect is enabled by default, intensity is 18%, heads emit 24 dots per tick, dot lifetime is 12 ticks, dot gravity is zero, dot opacity is 65%, and both head and dot fade durations are 4 ticks. Colors remain white.

Overall Size and Launch Speed are normalized around the selected configuration: the former 65% size and 250% speed now read 100%, with the same physical result. Baseline quad half-size is 0.00975 → 0.00585 blocks; baseline launch speed scales the underlying distribution by 2.5. Head Size remains 100%. Amount, opacity, lifetimes, gravity and drag retain their actual values rather than gaining hidden multipliers.

Revision-60 client files, serialized presets and server template settings convert the old speed and size values to the new units. Other selected settings are preserved. Existing values may round to the nearest slider step; the uploaded 250/65 values convert exactly to 100/100. Fresh installations and older test resets use the uploaded defaults.

The inactive Fixed Dot Distance default is 0.030 blocks. Fixed spacing remains Off, so Trail Dots (24 per tick) controls emission. Shared spread remains at 40%. No movement, collision, fade or color algorithms were changed; physics changes await discussion.

Validation: all uploaded default values checked against the config declarations and runtime values; normalized size/speed equivalence; isolated particle and preset migration checks; 10,000 matching spread directions; Java syntax parsing and source comparison of unchanged motion/collision/render implementations. No Minecraft build or in-game test was run. Remains beta while the reported Punchy animation issue is unresolved.

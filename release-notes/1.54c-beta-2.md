# 1.54c-beta-2

Includes the fixes from 1.53d-beta-18.

- Either grid click deselects an item selected by a mod, tag or keyword rule. Remove individual assignments and add !item_id only to lists whose broader rules still select it. If both lists select it, both receive an exception.
- Left-click reassigns to the whitelist; right-click reassigns to the blacklist. Reassignment clears the chosen list's per-item exception. Existing opposite-list conflict prompts remain available for explicit Rule and bulk assignment actions.
- Keep exceptions visible in Assigned and preserve them through Apply and reopening. Update Help and item-eligibility documentation.
- Reject deselection atomically if its exception cannot fit within the existing 1,024-character rule limit; preserve both rule lists and block-count overrides and show a short explanation.
- Keep exact-only pose and block-count selection behavior.

# Mallard Guard 1.53b-beta-4

Finalizes Spark Debris using the selected client configuration. Its only editable settings are Base Intensity, Perfect Intensity, and Damage Scaling, all ranging from 0 to 100%. Temporary motion, appearance, spread, and variation sliders are removed from the UI, client schema, and server enforcement template. Their selected values are now fixed baselines, retaining the same variation formulas and dotted tail behavior.

Spark Debris defaults: Base Intensity 12%, Perfect Intensity 8%, Damage Scaling 4%. Flying Sparks defaults: Base Intensity 12%, Perfect Intensity 16%, Damage Scaling 0%. Intensity changes affect amounts; the finalized motion remains fixed. Regular and perfect amounts remain independent. Damage Scaling increases the selected amount per intercepted damage point. Both effects retain the shared burst and active-particle budgets.

Revision-53 and revision-54 saved intensity values remain valid; old tuning slots become reserved again without shifting other settings. No unrelated settings from the uploaded config are adopted.

Beta status remains because rapid Punchy animation use can intermittently fail to render. Java syntax and source/math checks were performed; a local game build is still required.

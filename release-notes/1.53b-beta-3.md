# Mallard Guard 1.53b-beta-3

Spark Debris now exposes temporary tuning sliders for size, speed, velocity loss, gravity, drop delay, lifetime, fade duration, bounce strength, bounce loss, surface loss, tail duration, tail size, size variation, motion variation, fade variation, and spread bias. Percentage controls range from 0 to 100; timing controls use ticks. Settings save to the client config and participate in server presets, enforcement, search, and resets.

Flying Sparks retain their existing profile. Debris defaults approximately retain beta-2 behavior so tuning starts from a familiar baseline. Tail history is bounded to eight dots per head and creates no additional particle entities. Existing revision-53 intensity settings survive preset migration; former reserved slots receive tuning defaults.

Beta status remains because rapid Punchy animation use can intermittently fail to render. Java syntax and source/math checks were performed; compile and in-game appearance require a local build.

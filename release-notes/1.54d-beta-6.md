# 1.54d beta 6

- Removed Parry Disc rendering, settings, menu/search entries, preset migration behavior and textures. The overlay cleanup script deletes the old texture folder.
- Removed Center Impact Alpha Control. The existing PNG tint masks now select color coverage at full strength; overall Opacity remains adjustable. Size, Spin Speed, Opacity and Duration are the four remaining controls. The six artwork frames and six tint masks are unchanged.
- Rounded Flying Sparks Size Variance from 49% to 50%, preserving the selected spawn-size range. Flying Sparks lifetime variance is already 50–100% with a small lingering group and is unchanged.
- Historical preset lengths and zero-valued reserved positions are retained so saved settings keep their original meaning. Removed settings are not defined, rendered, or exposed in the UI.
- Mob perfect-parry window defaults to 15 ticks. Tactical and approach/pressure stance maximums both default to 2 seconds; existing randomized durations still range from 1 second to their configured maximum.

Config revision 86; networking protocol 66. Source/archive verification only. No Gradle, javac or Minecraft was run here; the user builds and tests locally. Asynchronous particle compatibility remains an identified, unfixed issue.

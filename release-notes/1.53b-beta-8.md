# 1.53b-beta-8

Adds an optional Aurukel Sparks Test using the spark particle class supplied by Aurukel, author of Terramity. Enable it under `/mgc` → Client → World Particles and apply. While enabled, new parry bursts use his effect instead of Flying Sparks and Spark Debris. Disable it to return to the existing effects. Already-spawned particles finish naturally.

The supplied particle's motion, gravity increase, friction decay, head lifetime, size changes and separate short-lived trail dots are preserved. The port uses NeoForge registration, the existing particle head budget and session cleanup. No Terramity installation is required.

The supplied class did not include its texture, burst emitter or the default value of Terramity's trail amount setting. This test uses Mallard Guard's white dot texture and a full spherical launch spread with the existing debris launch-speed distribution before its finalized speed multiplier. It starts at 12 heads per regular or perfect parry and 4 trail dots per head per tick; these are test settings rather than claims about Terramity's defaults. Intensity ranges from 0–100%, and Trail Dots from 0–16.

The collision profiler still measures only Flying Sparks and Spark Debris. It does not measure Aurukel's vanilla particle collision path. Leave profiling off for visual and frame-performance comparisons.

Flying Sparks and Spark Debris retain their existing physics, appearance and defaults. Older presets receive the new test controls with the switch off. This remains a beta while the reported Punchy animation issue is unresolved.

Validation: syntax parsing of 69 Java sources; exact comparison of the port's tick behavior with the supplied source after platform/config-name adaptation; verification that existing physics, rendering and profiler code are unchanged; stable setting-slot and UI-binding checks. No Minecraft build or in-game test was run.

# 1.53d-beta-5

- Renamed the third effect to Spark Tracers and its handling classes to GuardSparkTracerParticle / GuardSparkTracerConfig. Existing registration and config paths remain compatible.
- Ordered collapsible dividers as Flying Sparks, Spark Debris, Spark Tracers. Fixed the invalid empty-selection fallback that reopened closed groups.
- Made Base Intensity 0 disable an effect completely. Perfect Intensity now adds 0–100% to the base; Damage Intensity adds a percentage per incoming damage point. Older settings migrate into the new interpretation.
- Added Flying Sparks base color and spawn-color variation, defaulting to white with 30% subtle variation. Added fixed pale-gold variation for Spark Debris.
- Added fade-driven amber-white → amber → warm-gray cooling for Spark Tracers. Trail groups capture the head's spawn-time color and continue cooling together during their own fade.
- Shortened Spark Debris trail visibility/fading by 10%, from 3 to 2.7 ticks.
- Added clickable color previews beside hex inputs and a cached hue-wheel/triangle picker with exact hex entry, Done, and Cancel.
- Removed the unused particle-count overload, retired class names, unused divider metadata, and duplicate head-fade calculation. Updated search labels, enforced particle controls, cleanup script, and current documentation. Retained necessary preset migration code and stable resource identifiers.

Validation: 75 Java sources passed syntax parsing. Isolated physics, whole-tick trail groups, captured colors, gradient/HSV math, intensity scaling, spawning budgets, old preset migration, and picker resource/interaction checks passed. These checks use API fixtures; a full NeoForge build and in-game testing remain necessary.

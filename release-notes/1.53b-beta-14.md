# 1.53b-beta-14

- Removed the Terramity comparison particle, its registration, settings, and UI controls.
- Shooting Sparks now appear alongside Flying Sparks and Spark Debris instead of replacing them. Turning Shooting Sparks off affects only Shooting Sparks.
- All three effects share the burst's randomly favored side and the combined 512-per-burst / 1,024-active head budget. When capacity is limited, counts are apportioned across enabled effects.
- Replaced the circular head and soft rounded trail with solid square pixels and rectangular segments. Head size and trail thickness remain constant; only opacity fades.
- Preserved bounce path splits, interpolation, and the bounded trail history.
- Retired preset slots are ignored without moving active particle settings or Punchy pose settings.

For a source overlay, run `bash ./apply-source-cleanup.sh` before building to remove files left by older versions.

Validation: 71 Java sources parsed; isolated checks passed for simultaneous spawning, independent toggles, budget allocation, collision paths, interpolation, constant head size, trail expiry, and preset migration. A full Minecraft build and visual test remain necessary.

Remains beta while the rapid Punchy animation issue is unresolved.

# 1.54d beta 5

- Mob Guard exposes its master toggle, Difficulty, Parry Colors, Spawn Equipment and Mob Eligibility. Detailed combat controls are hidden from the menu and search; existing server-file tuning is preserved and is no longer copied through menu save packets.
- Difficulty defaults to 100% and scales approach, tactical, pressure, rush and repeat-guard chances. 50% halves their base chance; 0% prevents new decisions. Gear chance, timing, movement and animation selection are independent.
- Added three white-by-default mob tracer colors using the existing color picker. Each mob burst carries its palette to all viewers; its animated impact adapts to the same Start/Middle/End colors. Player palettes remain local. Existing impact alpha strength still applies.
- Added Mob Gear Assignments using the shared item browser, search, filters, assigned window, dragging, left/right clicks, rules and exceptions. Reset restores vanilla equipment allowed with vanilla axes blocked. Only usable armor, melee tools/weapons, ranged weapons and shields participate in generated equipment pools; existing equipped gear is not removed by these rules.
- Gear pools are cached by their two rule lists, invalidated on tag updates and cleared at server shutdown. Pool selection keeps common materials more likely than diamond/netherite. Empty pools add no equipment. Existing melee weapons and occupied armor slots are preserved; the previous ability to reroll ranged loadouts is retained.
- Beta 18 disc controls, camera-facing orientation, impact artwork, gameplay defaults and death cleanup are retained. The new disc appearance reference is for discussion; no disc redraw is included here.

Config revision 85; networking protocol 66. Source/archive verification only.

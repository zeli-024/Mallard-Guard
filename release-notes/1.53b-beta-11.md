# 1.53b-beta-11

Resets every Aurukel test setting to its defaults once when loading a client config older than revision 60. The test switch resets to Off; enable Aurukel Sparks again to try the new baseline. Older particle presets also receive reset Aurukel values. Flying Sparks, Spark Debris and other settings are preserved. Subsequent launches retain any new tuning.

Overall Size 100% now matches Spark Debris's average quad half-size: 0.015 blocks, shrinking to 0.009. Head Size defaults to 100%, so the head and dots use the same baseline. Spark Debris itself varies its size by ±20%; the test uses its average. This is a code-based baseline match, not an in-game judgment of an ideal size.

All three color controls reset to white. The prior white → orange → grey transition is therefore absent by default. Color capture and editable color controls remain available. A softer warm-amber treatment with opacity fading is a proposal for later discussion and is not implemented by this reset.

Shared heavier-side spread, adjustable head physics, trail physics, the unified control divider and expanded tuning ranges are retained. Amount returns to 12%, dots per tick to 4, speed and size to 100%, head lifetime to 12 ticks and dot lifetime to 5 ticks. All other Aurukel controls return to their declared defaults.

Validation: Java syntax parsing, isolated size/motion/fade/color checks, resetting every registered Aurukel setting and preserving a modified Flying Sparks setting, and preset roundtrip/migration/bounds checks. No Minecraft build or in-game test was run. Remains beta while the reported Punchy animation issue is unresolved.

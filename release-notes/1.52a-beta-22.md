# Mallard Guard 1.52a-beta-22

- Renamed Animated Sparks to Flying Sparks and replaced its controls with Base Intensity, Perfect Intensity, and Damage Scaling, each ranging from 0–100%.
- Added occasional electric sparks alongside the animated firework appearances, sharing the same particle budget.
- Flying sparks now cover the full sphere with a randomly selected heavier side for each burst.
- Varied launch speed, slowdown, gravity timing, size, lifetime, and animation phase independently to create uneven bursts.
- Retained the existing motion baselines and per-tick collision checks.
- Updated particle preset migration, reset controls, and server enforcement for the simplified settings.

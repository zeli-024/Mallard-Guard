# 1.53b-beta-9

Adds adjustable launch, head, dot and color settings to Aurukel Sparks Test. Enable the test under `/mgc` → Client → World Particles. Expand Aurukel Launch, Aurukel Head, Aurukel Colors or Aurukel Dots to tune it, then apply. Settings are saved in the client config and included in particle presets.

Launch controls cover amount, speed, speed variance and upward bias. Head controls cover start/end size, lifetime, gravity, gravity increase, velocity loss, increasing loss, collision size, opacity and fade duration. Dot controls cover start/end size, lifetime, gravity, velocity loss, opacity, fade duration and either dots per tick or fixed distance between dots. Fixed spacing carries distance across ticks and emits at most 32 dots per head per tick. Dots per tick ranges from 0 to 32.

The head defaults to white → orange → grey. All three colors are editable as hex RGB values, and Middle Color Point controls when orange is reached. Each emitted trail dot copies the head's current color and keeps it for its lifetime. This color transition is added for the reference test; it was not present in the supplied source. Head block collision and collision-free falling trail dots remain separate.

Dots now use consistent independent start/end sizes. The supplied code initially made dots 60% of the head size, but overwrote that size with 0.05 → 0.03 on subsequent ticks. The new default dot sizes preserve those subsequent values; newly emitted dots also start at the configured size. Other motion defaults retain the previous test values. Head and dot fades default to zero (constant opacity until removal).

Sizes are quad half-sizes in thousandths of a block: 50 means 0.05 blocks. Dot Distance and Collision Size use hundredths of a block: 10 means 0.10 blocks. Gravity controls are percentages of vanilla's particle gravity coefficient; they are not raw blocks per tick. Launch speed ranges from 0–300%, while amount and variance remain 0–100%.

The test still uses Mallard Guard's white dot texture and a configurable spherical burst emitter because those were not included with the supplied class. Flying Sparks, Spark Debris and their collision profiler are unchanged. Profiling still does not measure the Aurukel test effect. This remains a beta while the reported Punchy animation issue is unresolved.

Validation: Java syntax parsing, isolated particle/config checks for motion parameters, sizes, fade, color capture, fixed spacing and emission limits; extracted preset-parser checks for roundtrip, older-preset migration and invalid bounds; source comparison confirming the original particle implementations are unchanged. No Minecraft build or in-game test was run.

# 1.53d-beta-4

- Adopted the selected Shooting Sparks physics and appearance as fixed baselines.
- Simplified Shooting Sparks to Base Intensity, Perfect Intensity, and Damage Scaling, each 0–100%. Defaults are 16%, 16%, and 0%.
- Applied the selected Flying Sparks amounts (8%, 12%, 0%) and Spark Debris amounts (4%, 12%, 4%).
- Delayed low-energy floor sleeping until the third ground contact, allowing the second rebound to complete. Wall contacts no longer consume this ground-contact allowance. Selected bounce strength and decay remain unchanged.
- Kept two collision queries per tick, complete upright dot groups, shared budgets, and offscreen physics.
- Migrated older single-intensity and disabled settings into the new amount controls. Retired tuning fields are omitted from the UI and generated configuration.

Validation: Java syntax and isolated selected-default, rendering, second-rebound, settling, query-budget, spawning, amount-scaling, configuration, and preset migration checks. In-game testing remains necessary.

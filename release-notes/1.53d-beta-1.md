# 1.53d-beta-1

- Added independent Shooting Head Shrink and Shooting Trail Shrink controls, ranging from 0–100%. Both default to 40%, matching the supplied 0.05 → 0.03 size ratio. Zero keeps size constant.
- Shrinking advances in whole ticks. Every square from one tick group keeps the same age, size, and opacity; all appear and expire together.
- Applied the selected Shooting Sparks defaults: 48 squares per tick, launch speed 125%, overall size 85%, gravity 15, velocity loss 24%, and trail lifetime 12 ticks. Head and trail fade are zero, keeping full configured opacity until removal.
- Preserved the remaining selected defaults, square geometry, bounce paths, shared drawing, and particle physics calculations.
- Reused size and fade calculations within each dot group and retained the bounded sample storage.
- Earlier presets keep existing settings and receive the appended shrink defaults. Existing preset padding is ignored.

Validation: all 72 Java sources parsed; isolated checks passed for shrink ratios, synchronous tick-group shrinking, zero-fade opacity, group appearance and expiry, bounce paths, head interpolation, bounds, and preset migration. A Minecraft build and visual test remain necessary.

Use `bash ./apply-source-cleanup.sh` before building when overlaying older source. Remains beta while rapid Punchy animations can fail to render.

# 1.53b-beta-17

- Removed progressive reveal from Shooting Sparks' square trail. Every tick stamps its complete dot group along the traveled path immediately.
- Every dot created in the same tick now shares one age, opacity, and expiry time. Groups from later ticks remain separate.
- Bounce paths still split correctly, and the square count remains shared across the whole tick.
- Head physics, selected defaults, upright geometry, shared rendering, and head interpolation remain unchanged.
- Whole-tick birth stamps use integers instead of fractional timestamps.

Validation: 72 Java sources parsed; isolated checks passed for immediate whole-group visibility, equal opacity across a group, simultaneous expiry, bounce placement, head interpolation, storage bounds, and inactive cleanup. A Minecraft build and visual test remain necessary.

Use `bash ./apply-source-cleanup.sh` before building when overlaying older source. Remains beta while rapid Punchy animations can fail to render.

# 1.54c-beta-17

- Parry Disc is now solid with crisp 32-cell stepped edges and uniform opacity. Center Opacity was removed. Disc Size scales its starting diameter and expansion together. The captured plane stays upright and uses defender yaw only; observers see the same orientation.
- Shield Forward Bias is a client particle toggle, Off by default. It favors forward launches without a hard cone. Fall/wall-impact parries instead launch all three spark families in a horizontal ring with slight vertical variance. Particle motion, collision and trail drawing remain unchanged.
- Impact defaults: Size 250%, Spin 45 degrees/second, Opacity 100%, Duration 8 ticks, Alpha Control 100%. Flying Sparks, Spark Debris and Spark Tracers each default to 12 base lifetime ticks; existing variance remains. Tracer tail length is separate.
- Weapon timing defaults to 1 perfect tick within 6 total ticks; shields use 2 perfect ticks within 6 total ticks. Regular retaliation defaults to 40%, perfect to 80%. Defender pushback defaults to 50%, regular shield attacker pushback to 100%, weapon attacker pushback to 80%. Shield perfect cone settings remain separate.
- Mob stances use one continuous window: first 10 ticks perfect by default, then regular for the remaining stance. Removed the separate regular-duration and mob-blocking settings. Pressure stances use the approach duration maximum. Regular and perfect mob retaliation have separate On-by-default toggles; existing server multipliers and shield rules still apply.
- Mob eligibility is an exact whitelist: skeleton, zombie, piglin, zombified piglin, bogged and husk. Empty permits none. Boss exclusions remain. Fresh generated gear follows this list and never rolls axes; existing equipment is preserved. Bows and crossbows still prevent guarding. Piglin Brain ticks pause only while the bounded guard/counter goal owns combat.
- Mob defaults: hits 1, counter 20 ticks, approach/tactical chances 100%, tactical/approach maxima 1 second, tactical cooldown 100 ticks, guard movement 100%, approach distance 3 blocks, rush 100%. The master Mob guarding toggle remains Off by default.
- Death and respawn clear local guard/meter/reaction state, temporary screen feedback, input locks and owned animations. Dead input is rejected; server guard removal lowers the tracked pose and clears the player's status. Other players' world particles are allowed to finish normally.
- Reset values, control bindings, undo fields, search entries, server snapshots, validation and codecs use the new schema. Old preset positions stay reserved. Legacy mob retaliation migrates to both toggles; extra IDs migrate into the whitelist with previous exclusions honored when keeping settings.

Validation: source and package checks only. No Gradle build or game launch was run here. Build and multiplayer/death/respawn testing are performed on the user's device. Network protocol 64 requires matching client/server versions.
